# GANG HELPER

Скрипт для SA-MP, который упрощает рутинные действия с бандой и инвентарём на серверах **Evolve-Rp**. Всё настраивается в игровом окне настроек.

Автор: **OVERHATED**

> Скрипт работает только на серверах Evolve-Rp. На остальных серверах его функции отключены.

---

## Требования

- MoonLoader, SAMPFUNCS

## Установка

1. Скопируйте файл скрипта в папку `moonloader`.
2. Зайдите на сервер Evolve-Rp.
3. Откройте настройки командой `/gh`.

Настройки хранятся в `moonloader/config/ghelper.ini` и создаются автоматически.

---

## Возможности

### Банда

- **Флудер `/capture`** (`/ccapt`): автоматически отправляет `/capture` с заданной задержкой. Выключается, когда война началась. Можно скрывать лишние сообщения чата.
- **Авто `/get guns`** (`/agg`): автоматически берёт оружие со склада, как только открывается доступ.
- **Быстрая загрузка фуры на LSA** (`/flsa`): ускоряет загрузку материалов в фуру.
- **Быстрая маска** (`/fmask`): находит маску в инвентаре и надевает её.
- **Квест `/robbank`**: автоматически отвечает на вопросы Spongebozz.

### Дом на колёсах (ДНК)

- **Быстрый вход/выход**: автоматически подтверждает диалоги входа и выхода.
- **Быстрые команды для сейфа**: позволяют брать предметы из сейфа и класть их обратно одной командой. Скрипт сам открывает сейф и вводит пин-код.

| Предмет | Взять | Положить |
|---|---|---|
| Deagle | `/vd [кол-во]` | `/pd [кол-во]` |
| Shotgun | `/vs [кол-во]` | `/ps [кол-во]` |
| M4 | `/vm4 [кол-во]` | `/pm4 [кол-во]` |
| Материалы | `/vm [кол-во]` | `/pm [кол-во]` |
| Наркотики | `/vn [кол-во]` | `/pn [кол-во]` |

Подсказки:

- `/vm` и `/vn` без числа берут столько, сколько не хватает до максимума.
- `/pm 0` и `/pn 0` кладут максимум.
- Другой пин-код можно указать после количества: `/pm 100 1234`.
- Команды сейфа работают только при включённой опции «Быстрые команды для дома на колёсах».

### Материалы и наркотики

- Скрипт следит, сколько материалов и наркотиков у вас с собой, и подсчитывает, сколько осталось до максимума.
- Максимальные лимиты определяются автоматически.
- Значения можно вывести на экран. Доступны минималистичный режим, настройка шрифта и перемещение мышью.

### Очистка

- Удаление оружия ближнего боя.
- Удаление педов с анимацией `crckidle2`.
- Удаление граффити с ОГ.

## Окно настроек

Открывается командой `/gh`. Несохранённые изменения отмечаются жёлтой точкой. Чтобы записать настройки, нажмите **Сохранить настройки**.

| Вкладка | Разделы |
|---|---|
| **Банда** | Флудер `/capture`, Авто `/get guns`, Быстрая загрузка фуры на LSA, Авто-маска, Квест `/robbank` |
| **ДНК** | Вход и выход, Хелпер, Сейф, Команды |
| **Материалы** | Лимиты, Рендер, Шрифт, Положение |
| **Очистка** | Оружие, Педы, Граффити |
| **Общее** | Команды, О скрипте |

Названия команд меняются прямо в окне и применяются сразу. Допустимы латинские буквы, цифры и `_`, повторы не разрешены.

---

## Команды

Названия указаны по умолчанию, все они настраиваются.

| Команда | Действие |
|---|---|
| `/gh` | Окно настроек |
| `/ccapt` | Флудер `/capture` |
| `/agg` | Авто `/get guns` |
| `/flsa` | Быстрая загрузка LSA |
| `/fmask` | Быстрая маска |
| `/vd` `/vs` `/vm4` `/vm` `/vn` | Взять из сейфа |
| `/pd` `/ps` `/pm4` `/pm` `/pn` | Положить в сейф |
